## Execution-state gates

This index intentionally does not claim that a mutable workflow step is still
pending or already complete. Determine current state with the read-only commands
and invariant gates in [`HANDOFF.md`](HANDOFF.md):

1. verify the exact planning inventory and reviews;
2. verify local and remote checkpoint identities;
3. verify returned GitHub repository, security, PR, release, and Pages state;
4. execute the first unsatisfied authorized plan gate without repeating an
   already completed irreversible or externally visible action.

Every task uses a complete candidate commit, fresh specification review, fresh
quality review, exact-tip verification, a previously absent annotated
checkpoint, and immediate branch/tag publication. Review-fix commits remain
one logical change each.
