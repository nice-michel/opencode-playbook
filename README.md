# OpenCode Playbook

**Do the right thing, not the lazy or easy thing.**

OpenCode Playbook is an opinionated, installable working agreement for
OpenCode. It preserves Michel's exact 42-rule `AGENTS.md` while the supporting
OpenCode-native skills and lossless, backup-first installer are implemented.

The approved initial-release design is recorded in
[`docs/superpowers/specs/2026-09-16-opencode-playbook-initial-release-design.md`](docs/superpowers/specs/2026-09-16-opencode-playbook-initial-release-design.md).

## Status

**v0.1.0 implementation in progress.**

Task 1 is complete: the exact governing rulebook, architectural decision,
source-adaptation evidence, and managed-boundary documentation are committed.
Native skills, installer and restore tooling, lifecycle tests, public guides,
visual QA, release review, and publication remain pending.
