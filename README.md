# OpenCode Playbook

**Do the right thing, not the lazy or easy thing.**

OpenCode Playbook is being designed as an opinionated, installable working
agreement for OpenCode. It will preserve Michel's exact 42-rule `AGENTS.md`
while delivering the supporting procedures through OpenCode-native skills and
a lossless, backup-first installer.

The approved initial-release design is recorded in
[`docs/superpowers/specs/2026-09-16-opencode-playbook-initial-release-design.md`](docs/superpowers/specs/2026-09-16-opencode-playbook-initial-release-design.md).

## Status

The product design and written specification are approved. The implementation
plan is ready for owner review before execution begins.
