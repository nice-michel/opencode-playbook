# Backlog

The 0.1.0 corrective release has no deferred requirement. Everything in the
approved design remains release scope.

## After 0.1.0

- Audit a later stable OpenCode release before expanding support beyond
  OpenCode 1.18.31. OpenCode v2 remains explicitly untested and unsupported.
- Consider a native Windows installer only as a separately designed,
  transaction-safe implementation; the 0.1.0 POSIX scripts support Linux,
  macOS, and Windows Subsystem for Linux.

Each implementation task adds a dated entry only when it discovers a genuine
out-of-scope observation or explicitly authorized deferment. Release-scope work
never moves here merely because it is difficult.
